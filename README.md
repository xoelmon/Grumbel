# Grumbel

Demo de acción/supervivencia desarrollada en Unity. Este repositorio contiene el proyecto Unity completo.

Demo jugable: https://lagartixa-soundlab.itch.io/
Autor: Xoel Mon López -- www.linkedin.com/in/xoelmonlopez/

---

# Sobre el proyecto

Grumbel es una demo de novela visual corta en la que el jugador tiene que tomar diferentes deciciones.

Unity versión 6000.0.54f1 LTS 

---

# Objetivos

- Diseñar una historia interactiva con decisiones que afecten al desarrollo
  de la trama.
- Desarrollar la estructura narrativa completa: planteamiento, nudo y
  diferentes ramificaciones según las elecciones del jugador.
- Programar toda la lógica del juego en Ren'Py: sistema de decisiones,
  variables, ramas narrativas y flujo del guion.
- Aprender el flujo de trabajo de una novela visual desde el guion hasta la
  build final publicada.
